# E-commerce Sales Analysis

## Objective
Analyze sales data to find which categories and regions drive profit, how sales trend over time, and how discounts affect profitability.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Google Colab

## Steps
1. Data cleaning (removed duplicates, handled missing values)
2. Feature creation (month from order date)
3. Analysis using groupby (category, region, discount)
4. Visualization (bar and line charts)

## Key Insights
- Grocery and Furniture generate the highest profit; Clothing the lowest
- Electronics has high sales but lower margin
- East is the best region; West is the weakest
- Profit per order drops as discount increases

## Recommendations
- Focus marketing on the West region
- Improve Electronics margin
- Limit discounts to where they are really needed

## Note
Dataset is synthetic (generated with NumPy) for learning purposes.
